# Travel Earth

Прототип единого тайлового 3D-глобуса на [MapLibre GL JS](https://maplibre.org/) (`projection: 'globe'`) — без раздельных режимов "глобус" и "карта", с поддержкой спутникового слоя, многоязычных подписей и геопривязанных путешествий/объектов.

Выделен из [travel-globe](https://github.com/Gregory-GitTools/travel-globe) — контекст и техническое видение см. в [CLAUDE.md](CLAUDE.md).

Статус: только что начат, реализации пока нет.
