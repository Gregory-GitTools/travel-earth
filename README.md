# Travel Earth

3D-глобус на [MapLibre GL JS](https://maplibre.org/) (`projection: 'globe'`) с экскурсиями-набросками для будущих поездок: один глобус без раздельных режимов «глобус» и «карта», спутниковый слой, подписи на разных языках, свои фото на карте.

Выделен из [travel-globe](https://github.com/Gregory-GitTools/travel-globe) — контекст и техническое видение см. в [CLAUDE.md](CLAUDE.md).

## Что есть

- **Экскурсии** — файлы Markdown в папке [Экскурсии](Экскурсии/): остановки на карте с номерами, маршрут пунктиром, панель с текстом и справками, аудиогид с перелётами по остановкам и слайд-шоу фото Wikimedia Commons. Новую экскурсию можно заказать ИИ по [промту](Экскурсии/_Промт%20—%20как%20написать%20экскурсию.md).
- **Языки** — разговорник, словарь и общие фразы для стран экскурсий в папке [Языки](Языки/): фразы читаются вслух голосом нужного языка, есть проигрывание подряд. Экскурсия сама ссылается на разговорник своей страны. Новый язык — по [промту](Языки/_Промт%20—%20как%20написать%20разговорник.md).
- **Мои фото** — снимки из папки [Альбомы](Альбомы/) по координатам из EXIF.
- **Телефон** — панель экскурсии сверху под поиском, слайд-шоу под ней, карта ниже.

Файлы, имя которых начинается с «_», карта не читает: это промты и черновики.

## Запуск

Онлайн — GitHub Pages этого репозитория. Локально — `start.bat` (нужны Python 3 и Chrome/Edge); ярлыки «Travel Earth (локально)» и «Travel Earth (Edge)» на рабочем столе `start.bat` создаёт сам при первом запуске (или `install_desktop_shortcut.vbs`).
