# Промт: как написать разговорник для карты

Скопируйте текст ниже в ChatGPT (или другой ИИ), вместо [ЯЗЫК] и [СТРАНЫ] впишите свои. Готовый ответ сохраните файлом `Языки/<Название>.md`, например `Языки/Греческий.md`. Файлы, имя которых начинается с «_», карта не читает.

---

Составь короткий туристический разговорник: язык — [ЯЗЫК], страны — [СТРАНЫ]. Читатель говорит по-русски и не знает этого языка. Ответ дай одним блоком Markdown строго в формате ниже: его читает программа.

Шапка:
```
# Греческий
Язык: el-GR
Страны: Греция, Кипр
Источники:
- Название источника: https://ссылка

Два-три предложения о языке: где на нём говорят, легко ли читать, чем удивит туриста.
```
- «Язык:» — код языка и страны (it-IT, el-GR, pt-PT, ar-EG). По нему выбирается голос, который читает фразы вслух.
- «Страны:» — через запятую, по-русски, так же, как в строке «Страна:» экскурсий. У экскурсий этих стран появится ссылка на разговорник.
- «Источники:» — только реальные страницы, которые ты проверил (Wikivoyage Phrasebook, Википедия, официальные сайты). Не выдумывай ссылки.

Разделы — заголовки `## `, в таком порядке:
1. Произношение — 4–6 правил чтения обычными строками, без «- » в начале.
2. Самое нужное — здравствуйте, до свидания, спасибо, пожалуйста, извините, да / нет, не понимаю, говорите по-английски?, сколько стоит?, где туалет?
3. Числа — 1–10, 20, 50, 100, 1000; сегодня, завтра, вчера.
4. В аэропорту — регистрация, багаж, выход на посадку, как доехать до центра; затем диалог на паспортном контроле.
5. Как пройти — где находится…, далеко ли, налево, направо, прямо; затем диалог с прохожим.
6. Транспорт и такси — билет, остановка, адрес, «остановите здесь».
7. Аренда машины — бронь, права, страховка, топливо, парковка, местные дорожные особенности; затем диалог в прокате.
8. Гостиница — бронь, завтрак, выезд, багаж, поломки, вайфай; затем диалог при заселении.
9. Кафе и ресторан — столик, меню, вода, аллергия, счёт; затем диалог с официантом.
10. Магазин и деньги.
11. Экстренные случаи — помогите, скорая, полиция, аптека, кража, номер экстренных служб страны.
12. Надписи — вход, выход, открыто, закрыто, туалет, запрещено.

Каждая фраза — одна строка из трёх частей через « — » (пробел, длинное тире, пробел):
```
- Спасибо — Ευχαριστώ — эфхаристО
```
- первая часть — по-русски, вторая — на языке страны, его собственным письмом (греческие, арабские буквы и т. п.), третья — произношение русскими буквами;
- в произношении ударная гласная — ЗАГЛАВНАЯ буква: грАцие, эфхаристО;
- для письма справа налево (арабский, иврит) вторую часть всё равно ставь второй;
- внутри частей не используй « — », иначе программа ошибётся; вместо него запятая или скобки;
- переводи по смыслу, а не дословно: как сказал бы местный житель вежливо и просто.

Диалоги — подзаголовок `### Диалог: …`, затем фразы с говорящим в начале, через двоеточие:
```
### Диалог: заселение
- Вы: У меня бронь на две ночи — … — …
- Портье: Паспорт, пожалуйста — … — …
```
Говорящий — одно-два слова: Вы, Портье, Официант, Сотрудник, Прохожий, Пограничник.

Пояснение (например, про местный налог или чаевые) — обычная строка без «- » в начале.

Не пиши ничего вне этого формата: ни вступлений, ни выводов.
